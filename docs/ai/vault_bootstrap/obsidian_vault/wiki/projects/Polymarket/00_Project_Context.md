# Polymarket Project Context

## Goal

Build a local research-only MVP that combines odds ingestion, market/news context, sports statistics, odds movement, risk control, and final synthesis.

## Dashboard Outputs

- Forecasts.
- Confidence scores.
- EV estimates.
- Odds history.
- Paper-trading decisions.
- Win/loss rate.
- Calibration metrics.
- Simulated ROI.
- Drawdown.

## Boundary

FACT: The project is paper-trading and backtesting only.

INTERPRETATION: Architecture should prioritize reproducibility, provenance, safety boundaries, and performance reporting before live integrations.

GAP: Data providers, API terms, model strategy, and storage schema are not selected yet.
